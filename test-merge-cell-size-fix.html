合并单元格尺寸修复测试

🐛 问题描述

合并单元格显示的宽和高少了一行一列，rs和cs的问题。比如合并了3x3的单元格，实际合并的单元格显示只有2x2，但是点击选中的时候还是3x3。

🔧 修复方案

修复了多个文件中的尺寸计算错误：

  • useMerge.js：修复了 getCellStyle 中的循环边界条件
  • useTools.js：修复了 setMerge 调用时的参数计算
  • useExcel.js：修复了 Excel 导入时的合并单元格尺寸计算

问题根因分析

1. getCellStyle 中的循环边界错误

// 修复前（错误）： for (let i = cell.r; i <= cell.r + rs; i++) { // ❌ 多计算了一行 rh += sheet.hooks.resizeHook.getRowHeight(i) } for (let i = cell.c; i <= cell.c + cs; i++) { // ❌ 多计算了一列 cw += sheet.hooks.resizeHook.getColWidth(i) } // 修复后（正确）： for (let i = cell.r; i < cell.r + rs; i++) { // ✅ 正确的范围 rh += sheet.hooks.resizeHook.getRowHeight(i) } for (let i = cell.c; i < cell.c + cs; i++) { // ✅ 正确的范围 cw += sheet.hooks.resizeHook.getColWidth(i) }

2. setMerge 参数计算错误

// 修复前（错误）： sheet.hooks.mergeHook.setMerge(r, c, rr - r, cc - c) // ❌ 少了1 // 修复后（正确）： sheet.hooks.mergeHook.setMerge(r, c, rr - r + 1, cc - c + 1) // ✅ 正确的跨度

3. Excel 导入时的尺寸计算错误

// 修复前（错误）： const rowspan = merge.bottom - merge.top // ❌ 少了1 const colspan = merge.right - merge.left // ❌ 少了1 // 修复后（正确）： const rowspan = merge.bottom - merge.top + 1 // ✅ 正确的跨度 const colspan = merge.right - merge.left + 1 // ✅ 正确的跨度

测试步骤

  1. 基本合并测试：
    • 选择一个2x2区域（如A1:B2）并合并
    • 验证合并单元格的显示尺寸是否正确覆盖2x2区域
    • 点击合并单元格，确认选中范围也是2x2
  2. 大区域合并测试：
    • 选择一个4x3区域（如A1:D3）并合并
    • 验证合并单元格的显示尺寸是否正确覆盖4x3区域
    • 确认没有遗漏边界单元格
  3. Excel导入测试：
    • 导入包含合并单元格的Excel文件
    • 验证导入后的合并单元格尺寸是否正确
    • 确认合并区域与原Excel文件一致
  4. 边界情况测试：
    • 测试1x1"合并"（应该不产生合并效果）
    • 测试单行多列合并（如A1:E1）
    • 测试单列多行合并（如A1:A5）

验证要点

  • 视觉一致性：合并单元格的显示尺寸与选择范围完全一致
  • 边界准确性：合并单元格的边界精确覆盖所选区域
  • 交互一致性：点击合并单元格时的选中范围与显示范围一致
  • 导入导出一致性：Excel导入导出的合并单元格尺寸保持一致
  • 编辑功能正常：合并单元格的内容编辑功能正常工作

技术细节

合并单元格的坐标系统

// 合并单元格的定义： // - 起始位置：(r, c) // - 跨越行数：rs (row span) // - 跨越列数：cs (column span) // - 覆盖范围：行 [r, r+rs)，列 [c, c+cs) // 示例：从(1,1)开始的3x2合并单元格 // - 起始位置：(1, 1) // - rs = 3, cs = 2 // - 覆盖行：1, 2, 3 // - 覆盖列：1, 2 // - 覆盖单元格：(1,1), (1,2), (2,1), (2,2), (3,1), (3,2)

尺寸计算公式

// 正确的尺寸计算： let totalHeight = 0 for (let i = startRow; i < startRow + rowSpan; i++) { totalHeight += getRowHeight(i) } let totalWidth = 0 for (let i = startCol; i < startCol + colSpan; i++) { totalWidth += getColWidth(i) }

注意事项

  • 测试时注意观察合并单元格的边框是否完整覆盖选择区域
  • 验证合并单元格内容的对齐和显示是否正常
  • 确认取消合并后各单元格都能正常编辑
  • 测试不同尺寸的合并单元格（1x多列、多行x1、多行x多列）
  • 验证合并单元格在滚动时的显示是否正确
